usage: reqlore browser [-h] [--project PROJECT] [--proxy-port PROXY_PORT]
                       [--url URL] [--firefox-version FIREFOX_VERSION]
                       [--firefox-zip FIREFOX_ZIP] [--use-system]
                       [--channel {release,devedition}] [--wait]

options:
  -h, --help            show this help message and exit
  --project PROJECT     Project .rlr file. When given, the DOM Hunter
                        WebExtension is force-installed into the Firefox
                        profile, pre-configured with the project's bridge
                        token. Without --project, Firefox is launched without
                        the extension.
  --proxy-port PROXY_PORT
                        Proxy port to point Firefox at (default: settings
                        value).
  --url URL             Initial URL to open (default: the Reqlore UI).
  --firefox-version FIREFOX_VERSION
                        Pin a Firefox version (default: latest from Mozilla).
  --firefox-zip FIREFOX_ZIP
                        Use a pre-downloaded Mozilla zip/tar.xz instead of
                        fetching.
  --use-system          Prefer the host Firefox install over the managed
                        cache.
  --channel {release,devedition}
                        Firefox release channel to download. Defaults to
                        'devedition' when --project is given (required for the
                        DOM Hunter sideload), else 'release'.
  --wait                Block until Firefox exits (default: spawn and return).
