# HTTP/2 toolkit — `/h2/`

Parse a hex dump of HTTP/2 frames, or build a custom frame
(SETTINGS, PING, GOAWAY, RST_STREAM, WINDOW_UPDATE). Single page;
download the built frame as a `.bin` for use elsewhere. Uses
`hyperframe` under the hood.

## Where it is

- **URL:** `/h2/`
- **Nav:** *H2* in the top bar.
- Single page: top section parses, bottom section builds.

## Quick start (parse)

1. Capture H/2 bytes (Wireshark export, tcpdump hex view, your own
   socket logging).
2. Open `/h2/`. Paste into **Frame hex**.
3. **Parse frames**. Table renders one row per frame.

## Quick start (build)

1. Pick **Frame type** (default SETTINGS).
2. Fill in fields (id/value pairs for SETTINGS, opaque for PING, …).
3. **Build frame**. Hex output renders.
4. Optional: **Download .bin** to use in raw socket experiments.

## Routes

| URL    | Method | What it does                                                              |
|--------|--------|---------------------------------------------------------------------------|
| `/h2/` | GET    | Render the form. Hydrate from `?t=<token>` (PRGCache, 32-entry LRU).       |
| `/h2/` | POST   | `action=parse` or `action=build`. Stash in PRGCache, 302 to `?t=<token>`.  |

## Form fields

### Parse

| Field  | Type     | Default | Notes                                                  |
|--------|----------|---------|--------------------------------------------------------|
| `hex`  | textarea | empty   | Hex bytes. Whitespace, `:`, `0x` prefixes stripped.    |

### Build (all optional except `frame`)

| Field             | Type     | Default     | Applies to       | Notes                                                          |
|-------------------|----------|-------------|------------------|----------------------------------------------------------------|
| `frame`           | select   | `settings`  | all              | `settings` / `ping` / `goaway` / `rst` / `winupdate`.          |
| `sid1`…`sid6`     | text     | empty       | SETTINGS         | Parameter IDs (1-6 slots).                                     |
| `sval1`…`sval6`   | text     | empty       | SETTINGS         | Parameter values.                                              |
| `ack`             | checkbox | unchecked   | SETTINGS / PING  | If checked, send ACK frame (empty payload + flag 0x1).         |
| `opaque`          | text     | `reqlore!`  | PING             | 8-byte opaque data (truncated / padded to 8).                   |
| `last_stream_id`  | text     | `0`         | GOAWAY           | 31-bit last-stream-id.                                          |
| `error_code`      | text     | `0` / `8`   | GOAWAY / RST     | RST defaults to `8` (CANCEL); GOAWAY to `0` (NO_ERROR).        |
| `debug`           | text     | empty       | GOAWAY           | Debug string (bytes appended).                                  |
| `stream_id`       | text     | `0`         | RST / WINDOW     | Stream identifier.                                              |
| `increment`       | text     | `65535`     | WINDOW_UPDATE    | 31-bit increment.                                               |

## Parse details

`parse_hex()` is lenient: whitespace, tabs, newlines, colons,
`0x` prefixes all stripped before hex-decoding.

`parse_frames()`:

- Detects the HTTP/2 connection preface (`PRI * HTTP/2.0\r\n\r\nSM\r\n\r\n`) at the start; sets `stream.preface_seen = True`.
- Walks 9-byte headers: 3-byte length (big-endian), 1-byte type, 1-byte flags, 4-byte stream-id (mask `0x7FFFFFFF`).
- Decodes payload per type:
  - **DATA (0x0):** hex preview + UTF-8 body preview (first 64 bytes).
  - **SETTINGS (0x4):** if ACK flag, `settings_ack=True`; else parse 6-byte (id, value) tuples with names.
  - **PING (0x6):** 8-byte opaque hex; ACK flag tracked.
  - **GOAWAY (0x7):** `last_stream_id`, `error_code`, debug string.
  - **RST_STREAM (0x3):** `error_code`.
  - **WINDOW_UPDATE (0x8):** 31-bit `increment`.
  - **HEADERS / CONTINUATION (0x1 / 0x9):** raw HPACK hex (not decompressed).
- Truncated frames flagged with `error="frame extends past buffer"`.

## Build details

`hyperframe`-based; `_serialise(payload, type, flags, stream_id)`
prepends the 9-byte header. Output formatted via `to_hex()` — 32 bytes
per line, space-separated.

## How it integrates

**Producers / consumers:** none — output is a hex dump or `.bin`. Take
it to your own raw socket / curl `--http2-prior-knowledge` /
[Repeater](repeater.md)'s raw engine.

## Recipes

### Parse a SETTINGS frame with preface

Paste:

```
505249202a20485454502f322e300d0a0d0a534d0d0a0d0a000006040000000000000200000000000500004000
```

→ Two rows: preface marker, then `SETTINGS` with `(2, 0)` and `(5, 16384)`.

### Build a SETTINGS ACK

`frame=settings`, tick **ack**. Output: 9 bytes, `00 00 00 04 01 00 00 00 00`.

### Custom PING

`frame=ping`, `opaque=attack01`. Output: 17 bytes; the 8-byte opaque
field carries `attack01`.

### GOAWAY with PROTOCOL_ERROR

`frame=goaway`, `last_stream_id=100`, `error_code=1`, `debug=invalid encoding`. Pasted into a raw connection, the peer closes.

### WINDOW_UPDATE flow-control fuzzing

`frame=winupdate`, `stream_id=0`, `increment=0`. Build, ship via your
own raw H/2 client. Compliant peers must reject `increment=0` on a stream.

## Storage footprint

**Transient.** PRGCache holds `hex_text` / `stream` / `built_hex` /
`builder_err` under a 12-char token (32-entry LRU). No DB writes, no
`project_state` keys.

## CLI

No CLI surface. For programmatic use, import from `reqlore/h2_tool.py`:
`parse_hex()`, `parse_frames()`, `build_settings()`, etc.

## Troubleshooting

| Symptom                                                  | Cause                                                                  | Fix                                                                                              |
|----------------------------------------------------------|------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------|
| Parse returns nothing                                    | Input wasn't hex                                                       | Strip non-hex characters; `0x` and whitespace are auto-stripped, but everything else fails silently to empty. |
| HEADERS frame shows raw hex, not header names             | HPACK not decompressed in the toolkit                                   | Decompress externally (e.g. `hpack` Python lib) or use a real H/2 client.                        |
| Stream-id `0x80000000` came back as `0`                  | Top bit (reserved) is masked off via `& 0x7FFFFFFF`                     | This is per spec; the reserved bit must be zero. Not a bug.                                      |
| Built frame is rejected by the peer                       | Toolkit does no state-machine validation                                | That's your problem — the toolkit builds bytes, it doesn't validate H/2 protocol semantics.       |
| Output hex is in uppercase pairs                          | Hard-coded format                                                       | Reformat with `tr 'A-F' 'a-f'` if you need lowercase.                                            |
