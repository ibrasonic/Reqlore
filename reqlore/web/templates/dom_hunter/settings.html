Using the DOM Hunter extension

Launching the Reqlore-managed browser with reqlore browser automatically installs the DOM Hunter add-on into that profile and wires it to this project's bridge token. No manual setup is required.

  • Press F12 in any page to open Firefox DevTools and switch to the DOM Hunter tab. That panel shows live findings and postMessages for the current page.
  • Press Ctrl+Shift+D to open the sidebar version of the same view.
  • Press Ctrl+Alt+S to disable or re-enable tracing on the current tab.
  • Press Ctrl+Alt+F to jump back to this Reqlore findings page.

To use the extension in a browser other than Reqlore's managed Firefox (for example, plain Chrome / Edge / Brave for a non-XSS workflow), load the reqlore/dom_hunter/extension/ folder via about:debugging or your browser's developer-mode extension loader, then paste the bridge token shown above into the extension's Options page.
