Sequencer — token quality analyser

Paste opaque tokens (session IDs, CSRF tokens, password-reset codes, anti-bot nonces) and Reqlore measures their randomness. The basic report gives Shannon entropy, per-position character distribution and Hamming distance; Deep analysis additionally runs the per-character transition (Markov) test, NIST-style monobit / runs / poker / longest-run tests on every effective bit, a per-bit compression check and Bonferroni-corrected pairwise bit-bit independence test.

Transition (Markov) test — per character position

For each character position, builds the contingency table of (char in token N, char in token N+1) and runs a Pearson chi-square independence test. A failure means the character at that position in one token is predictable from the previous token.

Per-bit FIPS-style tests

Each character position is converted to a fixed-width bit slice based on its observed alphabet. The following four tests run on every bit position across the sample: monobit (balance of 0s and 1s), runs (number of bit runs), poker (chi-square over 4-bit nibbles, df 15), and longest-run (informational; flags when the longest run of 1s is much larger than log2 of the sample). A bit counts as "effective" when monobit, runs and poker all pass.
