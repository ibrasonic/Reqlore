Accessibility

Reqlore targets WCAG 2.2 Level AA. Every page is plain semantic HTML; all actions are reachable by keyboard; focus indicators are 3 px solid; no information is conveyed by colour alone.

To report an a11y bug, see the project page.

About

Reqlore is an accessible local-only web pentesting suite. It uses the httpx library for normal traffic, raw sockets for byte-exact requests, and mitmproxy for intercepting TLS. See the documentation for the architecture overview.
