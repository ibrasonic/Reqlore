Launch a pre-configured Firefox

Run the following from a terminal to open a dedicated Firefox profile wired to this proxy and trusting the Reqlore CA — no manual setup, no impact on your existing browser: 

reqlore browser --proxy-port {{ settings.proxy_port }} --url http://{{ settings.ui_host }}:{{ settings.ui_port }}/

First launch downloads the official Firefox portable build from Mozilla (~80 MiB, one time) and caches it under your user data folder. Subsequent launches are instant. For offline / air-gapped use, run reqlore prefetch-firefox first or pass --firefox-zip <path>.
