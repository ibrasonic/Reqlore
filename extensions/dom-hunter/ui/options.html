How DOM Hunter works

  1. Reqlore generates a canary string and a bridge token for each project. You see them on the Reqlore DOM Hunter settings page.
  2. This extension stores them locally and watches every page you visit (within the in-scope hosts you configure in Reqlore).
  3. The agent wraps dangerous JavaScript APIs (innerHTML, eval, ...) so it can detect when the canary value reaches them.
  4. Every match becomes a finding in Reqlore, complete with the JS stack trace and the captured argument.

Accessibility

The agent never modifies the inspected page's DOM tree, focus, or ARIA. All extension UI is plain semantic HTML, keyboard-operable, and designed to meet WCAG 2.2 AAA where practical.
