How this works

DOM Hunter hooks every common JavaScript sink that can execute strings as code (innerHTML, eval, document.write, and so on). When the canary value above reaches one of those sinks, you see a finding here.

Auto-inject puts the canary in location.hash, location.search, or window.name on every page load, so source-to-sink flows surface without you having to type anything by hand.

Everything also appears in the Reqlore web UI for later review, filtering, and export. Use Ctrl+Alt+F from anywhere in the browser to jump there.
